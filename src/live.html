⌖ Network Scan Configuration

How it works: choose an online Windows agent at this customer site. It checks a connected private subnet using ping, limited TCP connection probes, and ARP neighbors. Results can include devices without an RMM agent. Blocked or sleeping devices may not appear. Use the actual subnet shown by Windows ipconfig; this is not simulated discovery.
